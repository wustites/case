# 通知删除流程

> **核心问题**：版权权利人如何发出一份有效的 DMCA 通知（Takedown Notice）？

---

## 📋 基本概念

DMCA 通知（Notice of Infringement）是权利人依据 17 U.S.C. § 512(c)(3) 向网络服务提供者发出的、要求移除侵权材料的正式请求。它是"通知-删除"机制的起点：**只有符合法定要件的通知**，才能触发服务提供者"迅速移除"的义务，并使服务提供者免除因移除产生的责任。

一份无效的通知，平台没有移除义务；而一份**故意包含实质性虚假陈述**的通知，可能让发件人依据 § 512(f) 承担赔偿责任。因此，发通知既是维权工具，也伴随法律风险。

---

## 🔑 有效通知的六要素（§ 512(c)(3)(A)）

| # | 要素 | 说明 |
|---|------|------|
| ① | **签名** | 权利人（或授权代表）的物理签名或电子签名 |
| ② | **作品标识** | 指明被侵权的版权作品的名称/描述；单一网站多件作品可在一份通知中列举 |
| ③ | **侵权材料标识与定位信息** | 指明侵权材料及其足以让服务商定位的信息（通常是具体 URL） |
| ④ | **联系方式** | 足以让服务商联系投诉方的信息（地址、电话、邮箱） |
| ⑤ | **善意相信陈述** | 声明投诉方善意相信该使用未经权利人、其代理人或法律授权 |
| ⑥ | **准确性声明** | 声明通知信息准确，并愿受伪证处罚（under penalty of perjury），且投诉方获授权代表权利人行事 |

**关键提示**：
- 通知只需"实质合规"（substantial compliance）即可生效（§ 512(c)(3)(B)）；但缺失 ③ 作品/侵权材料标识与定位信息等关键要素时，平台可以不予处理。
- 要素⑤的"善意相信"是主观标准，但**不是"已获授权即合法使用"的绝对保证**——Lenz v. Universal Music Corp.（第九巡回上诉法院 2015）要求发件人发出通知前考虑合理使用。
- 要素⑥的"愿受伪证处罚"意味着通知是正式法律文件，虚假陈述可能触发 § 512(f) 责任。

---

## 📝 通知发给谁

- **平台登记代理人**：服务提供者依据 § 512(c)(2) 在美国版权局登记"指定接收通知代理人"（designated agent），其姓名与联系方式公布在版权局的代理人目录（Copyright Office's directory of service provider agents）中。**通知应发往代理人的公开联系方式，而非平台的一般客服邮箱。**
- 发错对象（如发给客服、发给个人用户）不产生法定效力，平台可视为未收到有效通知。

## 📋 通知模板（中文参考填写，实际使用时按平台要求调整）

```
DMCA 侵权通知（Takedown Notice）

致：[平台名称/指定代理人名称]
代理人邮箱/地址：[平台公开的代理人联系方式]

1. 签名（电子或物理）：[您的签名或授权代表签名]

2. 被侵权的作品：
   [作品名称、创作时间、首次发表情况；如适用请附版权登记号]

3. 侵权材料的位置：
   [侵权内容所在页面的完整 URL 列表，每条一行]
   [如可能，附侵权内容与正版内容的对比说明]

4. 我的联系方式：
   姓名：[您的姓名]
   地址：[地址]
   电话：[电话]
   邮箱：[邮箱]

5. 善意相信陈述：
   我善意相信，上述材料的使用未经权利人、其代理人或法律的授权。

6. 准确性声明：
   我声明，本通知中的信息准确无误，并愿受伪证处罚；本人为上述
   作品的权利人或经权利人授权行事。

日期：[YYYY-MM-DD]
签名：[您的签名]
```

## 📊 发出通知后的流程

```
权利人发送有效通知
    │
    ▼
平台验证通知六要素
    ├─ 有效 → 迅速移除/断开访问 → 转知被投诉用户（可提交反通知）
    └─ 无效 → 驳回并说明原因（不产生移除义务）
```

**预期处理**：法定标准是"迅速移除"（expeditiously remove or disable access），法律未规定精确天数；实务中主流平台通常在数小时内至数日内处理。

---

## ⚠️ 常见错误与风险

| 错误 | 后果 |
|------|------|
| 未指明具体侵权 URL | 通知无效，平台可不予处理 |
| 发给客服/错误收件人 | 视为未收到 |
| 笼统指控"整个网站侵权" | 不符合"足以定位"要求 |
| 未考虑合理使用即发通知 | 可能被认定违反 Lenz 案要求 |
| 故意作虚假陈述 | 承担 § 512(f) 赔偿责任（含诉讼费与律师费） |
