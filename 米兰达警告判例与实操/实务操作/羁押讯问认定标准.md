# 羁押讯问认定标准

> **核心问题**：何时触发米兰达警告义务？

---

## 📋 基本概念

### 1. 羁押讯问（Custodial Interrogation）

**定义**：
- **羁押（Custody）**：嫌疑人被限制人身自由，无法自由离开
- **讯问（Interrogation）**：执法人员直接提问或采取言行引诱嫌疑人作出陈述
- **羁押讯问**：在羁押状态下进行的讯问，必须事先宣读米兰达警告

### 2. 触发条件

米兰达警告义务在以下条件**同时满足**时触发：

1. 嫌疑人处于**羁押状态**
2. 执法人员正在进行**讯问**
3. 讯问由**执法人员**或其代理人进行

---

## 🔑 羁押认定标准

### 1. 主观标准 vs 客观标准

| 标准 | 内容 | 适用 |
|------|------|------|
| **主观标准** | 嫌疑人主观上是否感到被羁押 | 不采用 |
| **客观标准** | 合理人士在嫌疑人处境下是否感到被羁押 | 采用 |

### 2. "合理人士"测试（Reasonable Person Test）

**核心问题**：一个合理人士在嫌疑人的处境下，是否感到自己的行动自由受到实质性限制？

**考量因素**：

#### (1) 地点因素

| 地点 | 羁押可能性 | 说明 |
|------|-----------|------|
| 警察局 | 高 | 传统羁押场所 |
| 审讯室 | 高 | 封闭、隔离的环境 |
| 嫌疑人家中 | 中低 | 需考虑具体情况 |
| 公共场所 | 低 | 但需考虑警力部署 |
| 学校 | 中 | 对未成年人需特别考虑 |

#### (2) 时间因素

| 因素 | 影响 | 说明 |
|------|------|------|
| 讯问时长 | 较长时长增加羁押可能性 | 但无明确时间界限 |
| 时间段 | 夜间讯问可能增加羁押感 | 需考虑合理性 |
| 持续性 | 持续不断的讯问 | 可能构成羁押 |

#### (3) 警力部署因素

| 因素 | 影响 | 说明 |
|------|------|------|
| 警察数量 | 多名警察增加羁押感 | 需与嫌疑人数量比较 |
| 武器展示 | 展示武器增加羁押感 | 包括手铐等戒具 |
| 强制措施 | 使用强制措施 | 直接构成羁押 |

#### (4) 言行因素

| 因素 | 影响 | 说明 |
|------|------|------|
| 告知自由离开 | 可能减少羁押感 | 但非决定性因素 |
| 语气命令性 | 命令性语气增加羁押感 | 需考虑具体情境 |
| 威胁性言辞 | 直接构成羁押 | 包括明示和暗示 |

### 3. 特殊场景认定

#### (1) 交通拦截（Traffic Stops）

**一般规则**：交通拦截通常不构成羁押

**例外情况**：
- 拦截时间过长
- 搜查范围扩大
- 警察言行超出合理范围

#### (2) 街头盘问（Field Interrogation）

**一般规则**：街头盘问通常不构成羁押

**例外情况**：
- 警察使用强制手段
- 盘问时间过长
- 嫌疑人无法自由离开

#### (3) 监狱讯问（Prison Interrogation）

**一般规则**：在押人员因新罪被讯问时构成羁押

**考量因素**：
- 讯问是否与原判刑期有关
- 是否属于例行检查
- 是否有新的强制措施

#### (4) 学校讯问（School Interrogation）

**一般规则**：学校环境中的警察讯问可能构成羁押

**特殊考量**：
- 学生的年龄
- 学校环境的封闭性
- 是否有校方人员在场

## 📝 讯问认定标准

### 1. 直接提问

**定义**：执法人员直接向嫌疑人提出问题

**示例**：
- "你当时在哪里？"
- "你有没有参与？"
- "你认识被害人吗？"

### 2. 功能性等同提问

**定义**：虽然形式上不是问题，但实质上引诱嫌疑人作出陈述

**示例**：
- "我们已经掌握了证据，你最好说实话。"
- "你的同伙已经招供了。"
- "如果你合作，法官会从轻处理。"

### 3. 言行引诱

**定义**：执法人员通过言行创造引诱嫌疑人陈述的环境

**示例**：
- 故意在嫌疑人面前讨论案情
- 向嫌疑人展示证据并等待反应
- 使用心理战术引诱嫌疑人开口

### 4. 例外情况

以下情况**不构成讯问**：

| 情况 | 说明 | 示例 |
|------|------|------|
| **例行行政问题** | 与案件无关的身份确认 | 姓名、地址、出生日期 |
| **公共安全问题** | 紧急公共安全需要 | "武器在哪里？" |
| **自发陈述** | 嫌疑人主动陈述 | 嫌疑人主动承认罪行 |
| **背景交谈** | 非正式、非对抗性交谈 | 押解途中的闲聊 |

## 🎯 实务判断流程

### 第一步：判断是否羁押

```
是否在警察局/审讯室？
    ├─ 是 → 羁押可能性高
    └─ 否 → 进入下一步判断

嫌疑人是否被限制人身自由？
    ├─ 是（手铐、锁门等）→ 羁押
    └─ 否 → 进入下一步判断

合理人士是否感到无法自由离开？
    ├─ 是 → 羁押
    └─ 否 → 非羁押
```

### 第二步：判断是否讯问

```
是否直接提问？
    ├─ 是 → 讯问
    └─ 否 → 进入下一步判断

是否功能性等同提问？
    ├─ 是 → 讯问
    └─ 否 → 进入下一步判断

是否言行引诱？
    ├─ 是 → 讯问
    └─ 否 → 非讯问
```

### 第三步：综合判断

```
羁押 + 讯问 = 必须宣读米兰达警告
羁押 + 非讯问 = 无需宣读
非羁押 + 讯问 = 无需宣读
非羁押 + 非讯问 = 无需宣读
```

## 📊 典型场景分析

### 场景1：警察局讯问

**情况**：嫌疑人被带到警察局审讯室，警察直接提问

**判断**：
- 地点：警察局审讯室 → 羁押
- 行为：直接提问 → 讯问
- **结论**：必须宣读米兰达警告

### 场景2：街头盘问

**情况**：警察在街头拦住嫌疑人，询问其行踪

**判断**：
- 地点：公共场所 → 非羁押
- 行为：直接提问 → 讯问
- **结论**：无需宣读米兰达警告

### 场景3：交通拦截

**情况**：警察因交通违规拦停车辆，询问是否饮酒

**判断**：
- 地点：公共场所 → 非羁押
- 行为：直接提问 → 讯问
- **结论**：无需宣读米兰达警告（但需注意州法要求）

### 场景4：家中讯问

**情况**：警察到嫌疑人家中，要求其到厨房谈话

**判断**：
- 地点：家中 → 需具体分析
- 行为：直接提问 → 讯问
- **结论**：需综合考虑环境因素

### 场景5：监狱讯问

**情况**：警察到监狱讯问在押人员关于新罪

**判断**：
- 地点：监狱 → 羁押
- 行为：直接提问 → 讯问
- **结论**：必须宣读米兰达警告

## 📚 相关判例

### Miranda v. Arizona (1966)

- 确立羁押讯问必须宣读米兰达警告
- 定义羁押讯问的基本要素

### Berkemer v. McCarty (1984)

- 确认交通拦截通常不构成羁押
- 但可能因情况变化而构成羁押

### Stansbury v. California (1994)

- 强调使用"合理人士"客观标准
- 警察的主观意图不相关

### Thompson v. Keohane (1995)

- 确立羁押判断的两步测试
- 联邦法院对州法院判断进行独立审查

### Yarborough v. Alvarado (2004)

- 确认年龄不是羁押判断的一般因素
- 但J.D.B.案后有所改变

### J.D.B. v. North Carolina (2011)

- 将年龄纳入羁押判断的考量因素
- 扩展了"合理人士"标准
