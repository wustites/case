# 处罚案例数据库

> **核心问题**：如何查询 GDPR 罚款案例的完整数据与原始决定？

---

## 📋 工具一览

| 工具 | 维护方 | 内容 |
|------|--------|------|
| GDPR Enforcement Tracker | CMS 律师事务所 | 全球 GDPR 罚款案例数据库 |
| DPC 处罚决定库 | 爱尔兰 DPC | 跨境大案原始决定 |
| CNIL 处罚页 | 法国 CNIL | 法国处罚决定（含金额） |
| GDPRhub | noyb 维护 | 判例与执法案例社区维基 |
| noyb 执法档案 | 欧洲数字权利中心 | 投诉与执法进展 |

---

## 📖 一、GDPR Enforcement Tracker（重点工具）

- **网址**：enforcementtracker.com（CMS 律所维护，免费公开）
- **数据范围**：GDPR 生效以来的罚款决定，覆盖全部欧盟成员国 + 英国 + 挪威等
- **可查维度**：
  - 按企业/行业筛选；
  - 按罚款金额排序；
  - 按违规条款分类（第 5/6/12-22/32/33 条等）；
  - 按监管机构筛选；
  - 按国家筛选。
- **特色字段**：罚款金额（欧元）、最终决定状态（是否已终局）、违规条款、处理类型。
- **价值**：研究执法趋势与案例检索的一站式数据库。

---

## 📖 二、各国监管机构原始决定

| 机构 | 检索入口 | 说明 |
|------|----------|------|
| **爱尔兰 DPC** | dataprotection.ie → Decisions | 重大跨境处罚（Meta、TikTok、WhatsApp）的完整决定书 |
| **法国 CNIL** | cnil.fr → Sanctions | Google、Clearview 等处罚决定 + 新闻稿 |
| **英国 ICO** | ico.org.uk → Enforcement action | UK GDPR 处罚（含罚款与执法通知） |
| **德国 BfDI / 州机构** | 各州数据保护机构网站 | 分散执法决定 |
| **意大利 Garante** | garanteprivacy.it → Provvedimenti | Clearview、ChatGPT 等决定 |
| **西班牙 AEPD** | aepd.es → Resoluciones | 大量中小企业罚款案例 |

**价值**：原始决定书含事实认定与法律分析，是研究执法逻辑的一手材料。

---

## 📖 三、数据可视化与趋势工具

- **GDPR Fines Visualized**（各研究机构/媒体图表）：罚款时间线、行业分布的可视化 [以发布方为准]；
- **DLA Piper GDPR Fines & Data Breach Survey**（年度报告）：罚款总额与泄露统计（详见 [学术文献与行业报告.md](学术文献与行业报告.md)）；
- **IAPP 数据库**：执法与立法动态追踪。

---

## 📖 四、投诉与维权渠道

| 渠道 | 说明 |
|------|------|
| **noyb**（noyb.eu） | 欧洲数字权利中心：发起大规模投诉（Amazon、Meta 等案例源头），公布投诉进展 |
| **各 DPA 投诉入口** | 数据主体可向本国 DPA 在线投诉（GDPR 第 77 条） |
| **一站式机制** | 跨境案件由"主要机构"（lead supervisory authority）牵头，各国 DPA 参与 |
| **司法救济** | 对 DPA 决定不服可起诉；对控制者可直接起诉（第 79 条） |

---

## ⚠️ 使用提示

1. **金额口径**：部分罚款尚在上诉中（如 Amazon 案），引用时注明状态；
2. **币种**：多为欧元，英国为英镑，换算时注意；
3. **时效**：数据库与决定书以官方最新发布为准；
4. **合规参考**：罚款案例可作为企业风险评估与合规优先级设定的参照。
