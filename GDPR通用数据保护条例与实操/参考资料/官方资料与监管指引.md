# 官方资料与监管指引

> **核心问题**：GDPR 全文、监管指南与各国数据保护机构去哪里查？

---

## 📋 检索指引

| 类别 | 来源 | 内容/用途 |
|------|------|-----------|
| 法规原文 | EUR-Lex | GDPR (EU) 2016/679 多语言官方文本 |
| 统一指南 | EDPB | 同意、DPIA、跨境传输等专题指南 |
| 各国监管机构 | DPC / CNIL / ICO / BfDI / Garante | 执法决定、处罚公告、指引 |
| 充分性决定 | 欧盟委员会 | 第三国充分性认定名单 |
| 中国对照 | 国家法律法规数据库 | 《个人信息保护法》《数据安全法》 |

---

## 📖 一、法规原文

| 来源 | 说明 |
|------|------|
| **EUR-Lex**（eur-lex.europa.eu） | GDPR 正式文本，支持 24 种语言检索；检索词 "32016R0679" 或 "Regulation (EU) 2016/679" |
| **GDPR 全文索引** | 各条款（第 1-99 条）可逐条检索；配套文本含立法理由（recitals，共 173 条） |
| **相关法规** | 执法指令 (EU) 2016/680、ePrivacy 指令 2002/58/EC、数据治理法（DGA）、数据法（Data Act）等 |

---

## 📖 二、EDPB 指南（统一解释）

欧洲数据保护委员会（EDPB）发布具约束力的指南，是合规的重要参考：

| 指南主题 | 内容 |
|----------|------|
| **同意指南**（Guidelines 05/2020） | 同意的自由给予、捆绑同意、撤回 |
| **DPIA 指南**（Guidelines 04/2017） | 影响评估的触发与流程 |
| **跨境传输补充措施建议**（Recommendations 01/2020） | Schrems II 后的 TIA 与补充措施六步法 |
| **访问权行使指引**（Guidelines 01/2022） | 数据主体访问权（第 15 条）的行使指引 |
| **罚款计算指南**（Guidelines 04/2022） | 行政罚款的评估与计算 |
| **一站式机制指南** | 跨境案件的牵头监管机构协调 |

**检索**：edpb.europa.eu（公开征求意见的草案 + 最终版）。

---

## 📖 三、各国监管机构（DPA）

| 机构 | 国家 | 特点 |
|------|------|------|
| **DPC**（dataprotection.ie） | 爱尔兰 | 多数美国科技巨头的欧盟总部所在地 → 跨境处罚主力 |
| **CNIL**（cnil.fr） | 法国 | Google、Clearview AI 等处罚 |
| **ICO**（ico.org.uk） | 英国 | 英国脱欧后独立执法（UK GDPR） |
| **BfDI / 各州机构** | 德国 | 联邦与州双重体系 |
| **Garante**（garanteprivacy.it） | 意大利 | Clearview AI、ChatGPT 暂停事件（2023） |
| **AEPD**（aepd.es） | 西班牙 | Google Spain 案后的活跃执法 |

**用途**：查询各国处罚决定原文、投诉渠道、行业指引。

---

## 📖 四、充分性认定名单

- **欧盟委员会页面**（European Commission → Justice → Data protection → international transfers）列出获充分性认定的国家/地区/行业；
- 代表性认定：日本、英国、韩国、加拿大（部分）、阿根廷、新西兰、瑞士、以色列、乌拉圭等；
- 动态更新：每次认定决定附委员会报告（含定期复审机制）。

---

## 📖 五、中国对照

- **国家法律法规数据库**（flk.npc.gov.cn）：《个人信息保护法》（2021）、《数据安全法》（2021）、《网络安全法》（2016/2017）；
- **国家网信办**：数据出境安全评估、个人信息出境标准合同等配套规定；
- **信安标委（TC260）**：个人信息安全规范（GB/T 35273）等技术标准。
