## 一、民法典实施后民政部门的监护职责

### 1.1 民政部门作为监护主体的情形

根据《民法典》第 31、32、34、36 条，民政部门在以下情形承担监护相关职责：

| 情形 | 职责 |
|------|------|
| 监护人争议指定 | 指定监护人（第 31 条） |
| 无合适监护人 | 担任监护人/兜底监护人（第 32 条） |
| 紧急情况 | 安排必要的临时生活照料措施（第 34 条第四款） |
| 申请撤销监护资格 | 民政部门应当申请（第 36 条） |

### 1.2 关于意定监护的登记备案

- **目前国家层面尚无全国统一的意定监护登记备案制度，也没有面向公众的查询平台。**
- 公证办理后，相关信息由全国公证管理系统留档（供公证行业与主管部门管理使用，不面向公众查询）。
- 实务中建议将公证书副本送达常往的医院、银行等机构，并告知近亲属与监督人，以减少启用环节的障碍。
- 民政部门可依职责参与监护监督、纠纷调解等工作，具体以各地现行规定为准。

## 五、民政监护实践中的常见问题

1. **登记制度缺位**：尚无全国统一的意定监护登记制度，第三人核验协议主要依赖公证书本身
2. **监督缺位**：缺乏普遍建立的监护监督机制
3. **衔接不畅**：民政、法院、公证、医疗机构之间信息共享不足
4. **经费保障**：民政部门直接担任监护人时缺乏专项经费
5. **专业能力**：基层民政人员监护专业知识不足
