# 代孕相关法律以及实操知识库

> 系统性整理中国代孕（Surrogacy）相关法律法规、政策文件、实务操作指引、典型案例与参考资料。

---

## 📋 项目说明

中国现行法律没有一条面向所有自然人的“代孕一律违法”条款。《人类辅助生殖技术管理办法》作为部门规章，直接禁止医疗机构和医务人员实施任何形式的代孕技术；代孕协议还可能因违背公序良俗而无效，具体中介、医疗或交易行为也可能分别触发行政或刑事责任。跨境代孕、亲子关系和儿童权益则须结合个案事实判断。

本知识库以现行法律框架为基础，从法律条文、司法实践、实务操作、案例研究四个维度，系统梳理代孕相关的法律问题和应对策略，旨在为法律从业者、研究者和有需要的社会公众提供全面、客观的参考。

> ⚠️ **核心提示**：不得把部门规章对医疗机构、医务人员的禁令，简化为对所有主体、所有行为的同一种法律评价。本知识库仅供法律研究、风险教育与纠纷应对参考，不鼓励或指导实施代孕行为。

> 📎 **相关主题**：本库涉及的亲子关系与监护认定，可与 [意定监护](../意定监护/README.md) 知识库（《民法典》监护制度）对照阅读。
