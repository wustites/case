## 一、最高人民法院相关司法观点

### 1.1 代孕协议效力的司法态度

**最高人民法院《全国法院民商事审判工作会议纪要》（九民纪要，2019 年）**

九民纪要第 31 条明确：

> 违反规章一般情况下不影响合同效力，但该规章的内容涉及**金融安全、市场秩序、国家宏观政策**等公序良俗的，应当认定合同无效。

> 📌 代孕协议虽未被民法典明确列为无效合同类型，但因涉及**人类伦理、生育秩序等公序良俗**，法院普遍认定其无效。

### 1.2 最高人民法院系统的总体立场（定性归纳）

从最高法院系统的审判指导文件精神、公报案例及公开发布的裁判总结来看，一贯的倾向是：

- 代孕涉及社会伦理和人类尊严
- 代孕协议因违背公序良俗而无效
- 代孕产生的亲子关系认定应坚持"儿童利益最大化"

## 二、上海法院的裁判倾向

> 📌 经核实，**查无上海高院《关于审理代孕纠纷案件的指导意见》这一正式文件**。以下为基于上海法院公开裁判文书（尤其是全国首例代孕监护权纠纷案）归纳的裁判倾向，仅供参考。

### 2.1 裁判要点归纳

| 要点 | 说明 |
|------|------|
| 协议效力 | 代孕协议因违背公序良俗，应认定无效 |
| 亲子关系认定 | 坚持"分娩者为母"——代孕母为法律上的母亲 |
| 儿童利益 | 在处理子女抚养问题时以儿童利益最大化为核心 |
| 拟制血亲 | 与子女形成抚养关系的生父母之配偶，可构成有抚养关系的继父母子女关系（拟制血亲） |

### 2.2 抚养权争议的处理原则

1. 以子女利益最大化为首要原则
2. 考虑子女实际生活状况和情感联系
3. 哺乳期内的子女原则上随母生活

## 三、典型案例：全国首例代孕监护权纠纷案

### （2015）沪一中少民终字第 56 号（罗某、谢某诉陈某监护权纠纷案）

> 上海市第一中级人民法院二审改判。该案系**全国首例代孕监护权纠纷案**，并**写入 2017 年最高人民法院工作报告**。

**案件要点：**

- 陈某与罗某系夫妻，因陈某不孕，夫妻二人购买卵子并由罗某提供精子，委托他人代孕生下一对龙凤胎（陈某非基因母亲，也非分娩母亲）
- 子女出生后由陈某夫妻实际抚养
- 罗某因病去世后，罗某父母（祖父母）与陈某争夺子女监护权
- 法院认定：代孕所生子女的亲子关系认定，应坚持**"分娩者为母"**，并以**儿童最大利益**为原则

**裁判要点：**

1. 代孕协议因违背公序良俗而无效
2. 代孕母（分娩者）为法律上的母亲；罗某为生物学父亲
3. 陈某与子女无血缘关系，但系在婚姻关系存续期间一致同意代孕并实际抚养多年，与子女形成**有抚养关系的继父母子女关系**（拟制血亲），权利义务适用父母子女关系的规定
4. 陈某作为形成抚养关系的母亲，监护顺位先于祖父母
5. 儿童利益最大化原则下，由陈某继续监护更有利于子女成长

> 📌 本案中法院**仅认定了有抚养关系的继父母子女关系**这一路径，并未采用收养方式建立法律联系。

**影响：**
本案是中国法院首次系统处理代孕亲子关系问题的标志性案件，对此后代孕子女监护权、抚养权案件的裁判具有重要参考价值。

## 四、最高人民检察院相关意见

### 4.1 公益诉讼

最高检在代孕领域的司法态度（定性归纳）：

- 非法代孕侵害女性健康权、身体权
- 代孕中介涉嫌非法经营、非法行医
- 检察机关可依法对相关领域开展公益诉讼探索（涉及公共卫生、妇女权益）

## 六、亲子关系认定的法律路径

| 路径 | 可行性 | 说明 |
|------|--------|------|
| 分娩说（代孕母为母） | ✅ | 司法实践的普遍做法 |
| 基因说（提供卵子者为母） | ⚠️ | 需个案评估，非通说 |
| 有抚养关系的继父母子女关系（拟制血亲） | ✅ | 形成于**子女的生父母之配偶与子女**之间——即与生父/生母结婚并对子女有抚养教育的一方，可与子女构成拟制血亲（参见沪一中少民终字第 56 号案）；并非"委托方与代孕母之间有婚姻关系" |
| 收养 | ⚠️ | 需满足收养条件；前述首例代孕监护权案中法院未采用收养路径 |
| 事实抚养关系 | ✅ | 法院在抚养权案件中会考虑 |
